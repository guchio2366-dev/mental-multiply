# 暗算ドリル

二桁×二桁の掛け算を10問ずつ練習する、ブラウザ用の暗算ツールです。

## 使い方

1. 「10問の練習をはじめる」を押すとタイマーが開始します。
2. 答えを入力して、Enterまたは「答え合わせ」で判定します。
3. 正誤と正解を確認し、Enterまたは「次の問題へ」で進みます。
4. 10問目の回答確定でタイマーが停止します。「結果を見る」で正答率・合計タイム・1問あたりの時間・全問の答えを確認できます。
5. 「もう10問、練習する」で新しいセットを始められます。

## 仕様

- 10〜99同士の掛け算をランダムに10問生成。
- 同じセット内で同じ組み合わせは出題しません（左右を入れ替えた問題も重複扱い）。
- 時間制限なし。正誤確認中も計時し、10問目の回答確定で停止します。
- 空欄・不正な入力は回答として数えません。全角数字も使えます。
- 回答履歴の外部送信・永続保存はありません。

## ファイルと公開

`index.html` にHTML・CSS・JavaScriptをまとめています。外部ライブラリやビルドは不要です。ローカルのブラウザで直接開くこともできます。

GitHub Pagesでは、`main` ブランチのルートディレクトリを公開します。
